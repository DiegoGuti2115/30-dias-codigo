Antes de cortar

Normalizar sin reordenar el texto.

La limpieza es conservadora: unifica finales de línea, reduce espacios horizontales y conserva los límites de párrafo.

Se ajusta

CRLF/CR, espacios repetidos y más de dos saltos de línea.

Se conserva

El orden del contenido y una separación de párrafo significativa.

normalized = text.replace("\r\n", "\n")
normalized = whitespace.sub(" ", normalized)
normalized = trim_each_line(normalized)
normalized = collapse_blank_lines(normalized)
return normalized.strip()

Estrategia de corte

Fragmentos legibles, con solapamiento configurable.

El tamaño se mide en caracteres. El algoritmo busca el límite más natural disponible antes de realizar un corte estricto.

1.000caracteres por defecto
150de solapamiento
<overlap siempre menor que tamaño

Ejecutar desde cero

Local, verificable y sin credenciales.

El MVP requiere Python 3.11+. Sus dependencias incluyen PyMuPDF para PDF, python-docx para DOCX y pytest para pruebas.

PyMuPDFpython-docxpytest

Valida extensiones, archivos vacíos, rutas y documentos de más de 25 MiB antes de extraer texto.

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

python -m document_splitter.main \
  tests/fixtures/sample.txt \
  --chunk-size 30 --overlap 5 \
  --output output/sample-result.json

python -m pytest -q
