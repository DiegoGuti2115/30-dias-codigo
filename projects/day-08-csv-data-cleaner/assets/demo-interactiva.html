CIERRE

Qué demuestra este recorrido

Una demo local debe publicarse únicamente cuando devuelve 0 y muestra solo los fixtures sintéticos aprobados.

  • Entradas controladasUn CSV sintético y un plan JSON explícito.
  • Flujo verificableLa CLI valida, limpia y publica sin tocar el origen.
  • Salidas clarasUn CSV limpio nuevo y un resumen JSON estructural.
Limpieza final. Al terminar la grabación se elimina exclusivamente el directorio creado: rmdir /s /q demo-tmp.
