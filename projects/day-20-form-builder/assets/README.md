# Assets de demostración

La referencia visual de la Fase 7 se revisó en navegador sobre la aplicación local:

- Escritorio: viewport de 1440 px, sin overflow horizontal.
- Móvil: viewport de 390 px, sin overflow horizontal.
- Modo de prueba: tabs, controles etiquetados, errores por campo y confirmación local.
- Cabecera: exportación JSON, estado de persistencia y versión de la fase.

La captura puede regenerarse ejecutando `npm run dev` y usando la secuencia de `docs/DEMO_SCRIPT.md`. No se incluyen capturas binarias para mantener el repositorio ligero.
