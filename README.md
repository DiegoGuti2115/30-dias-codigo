# 🚀 30 Días, 30 Proyectos de Desarrollo

Reto práctico de ingeniería de software: construir y documentar 30 herramientas funcionales en 30 días consecutivos durante septiembre.

---

## 🎯 Objetivo
Desarrollar soluciones atómicas orientadas a automatización, frontend reactivo, sistemas de inteligencia artificial y microservicios, documentando el progreso diariamente en LinkedIn.

## 🛠️ Stack Tecnológico Global
- **Lenguajes:** Python 3.11+, TypeScript
- **Frontend / Frameworks:** Next.js, React, Tailwind CSS
- **Cloud & AI:** Azure AI Foundry, OpenAI API, Azure Service Bus, FastAPI
- **Herramientas & Persistencia:** Zod, SWR, IndexedDB, Redis

## ⚙️ Estructura de Cada Proyecto
Cada carpeta dentro de `projects/` es autocontenida:
1. `src/`: Código fuente ejecutable.
2. `README.md`: Explicación del problema resuelto, guía de instalación y captura de pantalla.
3. Archivo de dependencias (`requirements.txt` o `package.json`).
